# IA Médicale - Diagnostic du Diabète

## 📋 Description

Un système d'intelligence artificielle avancé conçu pour assister et améliorer le diagnostic du diabète. Ce projet intègre des modèles de machine learning performants pour analyser les données médicales et fournir des prédictions fiables et précises sur la présence et le type de diabète chez les patients.

**Entraîné sur plus de 100 000 cas de diagnostiques réels**, ce système offre une aide décisionnelle robuste pour les professionnels de santé.

## 🎯 Objectifs

- ✅ Améliorer la détection précoce du diabète
- ✅ Supporter les professionnels de santé avec des analyses basées sur l'IA
- ✅ Prévenir les complications liées au diabète par une identification précoce
- ✅ Fournir une solution scalable, maintenable et éthique
- ✅ Contribuer à l'amélioration de la qualité des diagnostics

## 📊 Composants du Projet

### Fichiers Principaux

- **`model.py`** - Modèle de machine learning pour la prédiction du diabète
- **`graph2.py`** - Analyse et visualisation des données médicales
- **`diabet_dataset.csv`** - Dataset contenant plus de 100 000 cas de diagnostiques
- **`accueil.png`** - Interface visuelle du projet

## 🛠️ Technologies Utilisées

- **Python** - Langage principal
- **Machine Learning** - Modèles de classification
- **Data Analysis** - Analyse et visualisation des données

## 🚀 Utilisation

1. Cloner le dépôt
```bash
git clone https://github.com/mekem688/IA-MEDICALE.git
cd IA-MEDICALE
```

2. Installer les dépendances requises

3. Exécuter le modèle de prédiction
```bash
python model.py
```

4. Générer les graphiques d'analyse
```bash
python graph2.py
```

## 📈 Résultats

Le système offre des prédictions fiables basées sur l'analyse de paramètres médicaux essentiels pour un diagnostic précoce et précis du diabète.
